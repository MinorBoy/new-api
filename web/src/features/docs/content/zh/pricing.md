# 模型与计费

new-api 支持 40+ 上游服务商的数百个模型。完整的**实时**模型清单、分组可用性与价格，请前往 [模型广场](/pricing) 查看。

## Seedance 公共模型 ID

终端用户只能看到并调用以下三个 Doubao Seedance 官方模型 ID：

- `doubao-seedance-2-0-260128`
- `doubao-seedance-2-0-fast-260128`
- `doubao-seedance-2-0-mini-260615`

此限制只适用于 Seedance 家族。GPT、GPT Image、Claude、Gemini、DeepSeek、GLM 等其他已接入模型仍按当前分组配置公开和调用。Seedance 的内部渠道模型与实际路由目标不会公开；直接调用非上述三个官方 ID 的 Seedance 模型会返回 `model_not_found`。

## 计费方式概览

每个模型按以下维度计费，具体倍率以模型广场的实时展示为准：

- **按 Token 计费**：输入（Prompt）Token 与输出（Completion）Token 分别计价。
- **按次计费**：部分图像、视频、音频模型按「每次请求」固定价格计费。
- **分组倍率**：不同用户分组可应用不同折扣倍率，在模型广场顶部切换分组查看。

## 如何查看价格

1. 打开 [模型广场](/pricing)。
2. 在顶部切换你的用户分组（如默认分组）。
3. 每张模型卡片显示：
   - 输入价格（每百万 token）
   - 输出价格（每百万 token）
   - 上下文窗口、能力标签
   - 支持的接口端点

点击任意模型卡片可展开详细的计费明细、调用示例与支持的参数。

## 计费单位

- Token 计价的模型，额度按「输入 token × 输入倍率 + 输出 token × 输出倍率」折算。
- 价格单位为人民币元（CNY），1 元 = 500000 额度单位（具体以系统配置为准）。

## 分组与可用性

并非所有模型对所有分组开放。若某个模型在模型广场显示「不可用」，可能是：

- 当前分组未配置该模型的上游渠道。
- 你的账号分组未开放该模型权限。

联系管理员可调整分组配置。详见 [计费规则](/docs/billing-rules) 了解计费、缓存折扣与失败不扣费策略。
