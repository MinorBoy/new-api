# 导入审查返回能力设计

## 背景

渠道配置导入向导在发布审查阶段会显示未解决的价格分组警告。当前界面没有返回定价审查或路由差异审查的操作入口，管理员无法修正选择后沿服务端状态机重新暂存和校验，导致合法批次停留在发布审查。

## 目标

在发布审查区域提供返回审查的可见、可访问按钮。返回后沿既有前端回调和服务端接口重跑定价审查、路由差异、暂存和校验，不修改服务端状态规则，不接触渠道凭据，不增加新的批次。

## 方案

`PublishReviewStep` 接收可选的 `onBack` 回调，在发布按钮旁显示使用现有 `Back` 翻译键的次要按钮。向导在发布审查阶段将其绑定到 `setReviewStep('pricing')`。管理员修正分组并继续后，现有逻辑会调用定价审查接口、重新暂存并进入路由差异审查；路由审查继续后仍会调用现有校验接口。

该入口只在批次允许返回审查时提供；不改变发布按钮的 blocker 判断。测试从用户视角验证按钮可见、点击后进入定价审查，并保留原有发布审查确认逻辑。

## 验证

- 组件回归测试覆盖发布审查返回按钮的可访问名称和回调。
- 向导回归测试覆盖从发布审查返回定价审查并继续提交选择。
- 运行受影响 Bun 测试、TypeScript 类型检查、相关 lint 和生产构建。
