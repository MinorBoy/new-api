# 素材库 API Key 隔离设计

## 背景

当前素材表已通过 `created_by_token_id` 记录创建素材的 API Key，但素材库页面使用登录会话直接调用素材接口。登录会话没有 `token_id`，因此页面创建的历史素材被写入 `created_by_token_id = 0`。素材列表、查询、刷新和视频引用目前只按用户隔离，没有按 API Key 隔离。

本次改动将 API Key 设为素材归属和访问控制的唯一边界。用户必须先在素材库页面选择一个已启用 API Key，才能查看或创建该 Key 绑定的素材。

## 目标

- 素材库页面默认不选择 API Key，也不加载素材。
- 选择已启用 API Key 后，只展示该 Key 创建的素材。
- 创建、查询、刷新和视频引用均使用所选 API Key 认证。
- 同一用户的不同 API Key 之间也严格隔离素材。
- `created_by_token_id = 0` 的历史素材不迁移，并在所有 API Key 下隐藏。
- 视频生成页的素材选择器只展示当前视频 API Key 绑定的素材。

## 非目标

- 不提供历史未绑定素材的迁移界面或自动迁移。
- 不允许禁用、过期、额度耗尽或已删除的 API Key 管理素材。
- 不改变素材与 Secure 上游渠道、上游 API Key 的既有固定绑定关系。
- 不新增真实上游素材作为本次验收数据。

## 方案选择

采用“所选 API Key 直接作为素材接口 Bearer 凭证”的方案。

素材页仍通过登录会话获取当前用户的 API Key 列表及选中 Key 的完整值，但素材接口本身不接受客户端声明的 `token_id`。前端使用所选 API Key 调用素材接口，后端从鉴权上下文取得可信的 `user_id` 和 `token_id`。

未采用以下方案：

- 登录会话附加 `token_id` 参数：需要额外校验 Key 归属和状态，并形成两套素材身份分支。
- 页面和外部客户端使用不同认证方式：兼容面更大，但增加权限逻辑和测试矩阵，本版本没有必要。

## 后端设计

### 认证要求

`/api/v3/assets` 路由继续支持 API Key 请求，但所有素材操作要求鉴权上下文中存在有效的 `token_id`。登录会话直接访问素材接口时返回 `asset_token_required`，不再创建或返回未绑定素材。

API Key 的启用状态、有效期和额度状态继续由现有 Token 鉴权负责。素材服务不信任请求参数中的用户或 Key 标识。

### 数据范围

以下操作均以 `user_id + created_by_token_id` 作为数据范围：

- 创建素材
- 列出素材
- 获取素材及上游状态
- 刷新素材状态
- 解析视频请求中的 `asset://...` 引用

跨 Key 访问统一返回素材不存在，避免泄露其他 Key 下的素材是否存在。`created_by_token_id = 0` 的历史记录不会匹配任何有效 API Key，因此自然隐藏。

### 服务接口

素材控制器和服务方法显式传递 `token_id`。素材所有权查询同时匹配素材 ID、用户 ID 和创建 Key ID。视频素材路由中间件从当前视频请求的 API Key 鉴权上下文读取 `token_id`，并将其传给素材引用解析服务。

### 幂等兼容

新创建请求的幂等散列包含 `token_id`，使同一用户的不同 API Key 可以安全使用相同的 `Idempotency-Key`。

为兼容升级前由有效 API Key 创建的素材，幂等查询先按新的 Key 级散列查找，再按相同 `user_id + token_id` 查找旧散列。旧散列只用于恢复原素材，不用于跨 Key 命中。该方案不需要修改数据库索引，继续兼容 SQLite、MySQL 和 PostgreSQL。

## 前端设计

### API Key 选择

素材页顶部增加 API Key 选择区，复用视频生成页现有的 API Key 分页加载和完整 Key 获取能力。选择项展示 Key 名称、分组和脱敏值，不向用户展示完整 Key。

选择框只包含已启用的 API Key，并且默认值为空。素材创建请求进行中暂时禁用选择框，避免请求期间切换身份。

### 素材页面状态

- 未选择 Key：不请求素材；禁用公网图片 URL 输入框和创建按钮；列表区显示选择提示。
- 正在读取 Key：显示加载状态，创建和素材操作不可用。
- 已选择 Key：使用完整 Key 作为 Bearer 凭证加载、创建和刷新素材。
- Key 失效或请求失败：显示明确错误和重试入口，不回退到登录会话请求。
- 切换 Key：查询缓存键包含 `token_id`，立即切换到新 Key 的加载状态，不展示旧 Key 的素材。

创建和刷新 mutation 捕获发起操作时的 Key 身份，并只失效对应 Key 的素材缓存。

### 视频生成页联动

视频生成页把当前选择的 API Key 身份传给素材选择器。未选择视频 API Key 时不加载素材；切换视频 API Key 时清空已选择的素材 ID，再加载新 Key 的素材。这样页面展示与后端视频引用校验保持一致。

### 国际化与可访问性

新增的标签、提示、空状态和错误文案全部通过 `t(...)` 使用，并通过项目脚本同步到 `en`、`zh`、`zh-TW`、`fr`、`ja`、`ru`、`vi` 七个语言文件。

选择框具有可访问名称；禁用、加载和错误状态同时提供视觉与语义反馈。键盘用户可以完成选择、创建和刷新操作。

## 错误处理

- 无 API Key 身份：返回 `asset_token_required`。
- 素材不属于当前 Key：返回 `asset_not_found`，HTTP 404。
- Key 被禁用、过期、耗尽或删除：沿用 Token 鉴权错误。
- 完整 Key 获取失败：前端显示错误，不发起素材请求。
- 上游素材创建或刷新失败：沿用现有素材错误码和状态保留机制。

## 测试与验收

### 后端

- 验证 `token_id = 0` 时拒绝所有素材操作。
- 验证列表、查询、刷新和视频引用同时匹配用户与 API Key。
- 验证同一用户的不同 Key 无法访问彼此素材。
- 验证历史未绑定素材不会出现在任何 Key 下。
- 验证新幂等散列按 Key 隔离，并兼容相同 Key 的旧散列重试。
- 使用 GORM 查询，覆盖 SQLite 测试路径并保持 MySQL、PostgreSQL 兼容。

### 前端

- 未选择 Key 时不请求素材，且创建控件禁用。
- 选择 Key 后请求使用对应 Bearer 凭证。
- 切换 Key 时隔离列表缓存。
- 创建和刷新使用当前 Key。
- 视频页切换 Key 时清空已选素材并加载对应列表。
- Key 加载失败和素材请求失败均显示可访问错误状态。

### 验证命令与页面验收

运行受影响 Go 测试、前端行为测试、TypeScript 类型检查、涉及文件 lint 和生产构建。随后在本地素材库与视频生成页面验证未选择、选择、切换、空状态和禁用状态。本次验收不创建新的真实上游素材。
