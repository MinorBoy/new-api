# ARK SDK 真实配置 E2E 实施计划

**目标：** 使用导入的渠道、模型和供应商成本数据驱动 ARK SDK 视频验收 seed 与 E2E 流程，仅对上游 HTTP 响应进行 mock。

**架构：** 将 `e2e/testdata/channel-config-v1.json` 解析为渠道定义、路由目标和成本规则定义。使用当前已注册的供应商类型创建每个测试渠道，其中包括把旧的 `CH-4STOKEN` 修正为类型 `209`；在渠道上保留导入的上游模型，并持久化每条匹配的成本规则，不替换其计费模式、币种、价格或汇率。mock 服务器接受各真实任务适配器所选择的 endpoint 和协议形态。

**验证：** 聚焦单元测试断言导入的类型、模型和价格得到保留。素材矩阵 E2E 断言各适配器特有的上游路径、映射后的上游模型、计费规则快照，并区分 26 个完整成功目标与 72 个提交前合约阻断目标。随后针对控制台 MySQL 数据库重新运行持久化 seed，并检查已存储记录。
