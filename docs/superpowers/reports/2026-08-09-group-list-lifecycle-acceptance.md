# 分组列表生命周期验收报告

日期：2026-08-09

## 验收结论

分组列表的启用、停用和删除生命周期已完成自动化测试、桌面与移动浏览器验收、停用门禁 Canary 和真实上游视频 Canary。

新建分组默认启用；停用状态可以保存并在刷新后恢复；停用 `default` 必须二次确认；删除必须二次确认且会清理该分组拥有的定价、能力和路由配置；被用户或令牌引用的分组不能删除。停用分组不会再出现在可分配列表中，已有停用分组账号的请求会在任务创建、成本记录和上游调用之前返回 `403`。

本轮真实请求在成本核算严格模式和全局最低预计毛利率 `50%` 下成功命中 Paipu `#22` 的 `lec-seedance-2-0-933-stable`。任务完成、视频可读取、收入与供应商成本均已结算，毛利率为 `52.3835%`。

## 功能范围

- 分组状态设置兼容旧数据，缺失状态按启用处理。
- `PUT /api/option/group-settings` 原子保存倍率、状态、充值倍率、说明和关联配置。
- 停用分组从公开分组、模型列表、用户和令牌分配入口中排除。
- 已处于停用分组的账号在认证后、计费和路由前返回 `403`。
- 删除前检查用户和令牌引用，确认删除后清理分组拥有的全部配置。
- 分组列表新增状态列和 Switch，新建分组默认启用。
- `default` 停用和所有分组删除均使用二次确认弹窗。
- 七种前端语言均已补齐新增文案。
