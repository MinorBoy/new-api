## 合同缺陷根治

上一轮 36 条阻断不是继续兼容的历史数据，而是“最新收录表合同”和“协议实现/模板生成器旧假设”不一致。本轮按上游协议和最新收录表共同根治：

- Cangyuan 使用更新后的渠道文档实现专属请求方言，支持参考图、参考视频、参考音频及首尾帧字段，统一校验 480p/720p、4 至 15 秒和参考视频总时长 15 秒；普通模型上限为素材 `4/3/1`、总素材 8，`sd5-seedance-*` 上限为 `9/3/3`、视频与音频合计 3、总素材 12，不再按文生视频渠道拒绝全部媒体素材。
- CLMM 删除静态模型前缀白名单，提交和路由合同共享同一个模型控制语法解析器；普通模型时长边界统一为 4 至 15 秒，模型名内带固定时长控制时由模型语法负责。
- Dimensio 删除静态模型白名单，模型目录以导入快照为准；协议层只校验非空模型、协议分辨率和已验证的系列差异，`jmg-*` 总素材上限为 12，其余已导入系列为 15。
- 模板生成器在生成阶段执行 Cangyuan、8yes、MegaByAI、CLMM 和 Secure 企业组合同门禁，源表再次出现不可能发布的能力组合时直接生成 `FAIL` 问题。
- 时长合同同时支持连续区间和离散值，例如 `4,8,12` 会生成 `duration_values`，不再被错误扩张为 `4-12` 的任意整数范围。
- E2E 种子从目标允许比例中选择请求比例，优先 `16:9`，否则使用首个合法值；CLMM 仅允许 `9:16` 的目标不再被种子程序硬编码的 `16:9` 误伤。

根治后的本地合同回归为：导入目标 167、合同通过 167、合同阻断 0、禁用价格 0。

## 售价与供应商成本

Seedance 用户售价继续使用官方 Token 公式，并与供应商成本完全独立：

```text
总 Token = ceil((输入视频时长 + 输出视频时长) × 输出宽 × 输出高 × 输出帧率 / 1024)
用户基础售价 = 官方 USD/1M Token × 总 Token / 1,000,000
最终用户售价 = 用户基础售价 × 分组倍率
```

测试分组倍率为 `1.25`。供应商成本分别按批次 20 活动规则中的按时长、按次或按 Token 合同结算，不参与用户售价计算，也不会生成 `seedance_price_matrix=0.91` 一类推导倍率。参考视频时长参与官方用户 Token 公式；供应商成本是否使用请求时长、终态时长或终态 Token，则严格由对应上游成本规则决定。
