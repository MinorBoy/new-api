# 任务审计数据悬停预览与日志紧凑布局设计

## 背景

任务日志中的“请求数据”“上游响应（创建任务）”“任务详情”三列目前只提供“查看”按钮，必须点击后才能在 Dialog 中读取完整数据。管理员在连续排查多个任务时需要频繁打开和关闭 Dialog，浏览效率较低。同时任务日志与绘图日志的桌面表格留白偏大，横向列间距和行高使同屏可见记录数量不足。

## 目标

- 三个任务审计数据列支持悬停查看完整 JSON，并支持在悬停层内滚动。
- 保留点击打开完整详情 Dialog 的现有能力，便于稳定阅读和复制长数据。
- 键盘聚焦“查看”入口时也能获得与悬停一致的预览。
- 收紧任务日志与绘图日志的桌面表格横向留白和行高，提高同屏信息密度。
- 不修改普通使用日志、移动端卡片、接口字段、权限规则或数据格式。

## 交互设计

三个审计数据列继续显示带查看图标的“查看”按钮，保持入口简洁且不直接把长 JSON 塞入表格。按钮承载两种互补交互：

- 鼠标悬停约 250 毫秒后打开 Preview Card，展示格式化后的完整 JSON。
- Preview Card 最大宽度约 560 像素、最大高度约 420 像素；内容区域独立滚动，鼠标移入浮层后保持打开。
- Preview Card 顶部展示当前列标题和复制按钮，复制内容与现有详情 Dialog 一致。
- 点击“查看”按钮时关闭悬停预览并打开现有详情 Dialog。
- 键盘聚焦按钮时打开预览，按 `Enter` 或空格打开详情 Dialog，按 `Esc` 关闭当前浮层。
- 数据为空时继续显示 `-`，不提供空预览或空 Dialog。
- 触摸设备不依赖悬停，继续通过点击进入详情 Dialog。

悬停预览用于快速比对，详情 Dialog 用于长时间阅读，两者使用相同的 JSON 格式化结果，避免内容差异。

## 视觉与布局

本次不改变页面配色、字体或整体信息架构。视觉重点是形成一个安静、可扫描的“审计数据窗口”：

- Preview Card 使用现有 `popover` 语义颜色、细边框和轻阴影，不增加装饰性色彩。
- JSON 使用项目现有等宽字体和紧凑行高；复制按钮使用图标和现有提示文案。
- 浮层宽度受视口约束，避免在较窄桌面窗口中越界。
- 任务日志与绘图日志的表头和单元格横向内边距从当前 8 像素收紧到约 6 像素。
- 两类日志的桌面行高从当前约 60 像素收紧到约 48 至 52 像素，并保留状态徽标、双行时间和任务 ID 的完整可读性。
- 普通使用日志维持当前密度；移动端继续使用现有卡片布局，不套用桌面表格的紧凑规则。

## 组件与数据流

`TaskAuditDataCell` 继续拥有当前单元格的打开状态，并新增悬停预览状态。格式化逻辑从详情 Dialog 内部提升为同模块可复用的稳定能力，悬停预览和详情 Dialog 共享同一字符串结果。

悬停层复用项目已有的 Base UI `HoverCard` 组件，不新增依赖。复制操作继续复用 `useCopyToClipboard`。点击入口时先关闭 Hover Card，再打开 `TaskAuditDataDialog`，避免两个浮层同时可见。

日志密度通过 `UsageLogsTable` 按 `logCategory` 提供列样式和行样式：仅 `task` 与 `drawing` 应用紧凑类名，`common` 保持原状。样式通过现有 `DataTablePage`、`DataTableRow` 和 `getColumnClassName` 接口传递，不修改通用表格组件的全局默认值。

## 备选方案

### Tooltip 展示完整 JSON

实现最轻，但 Tooltip 不适合承载可滚动、可复制的长内容，鼠标在触发器与内容之间移动时也更容易意外关闭，因此不采用。

### 点击和悬停共用 Popover

可以减少一个浮层组件，但长数据的稳定阅读、焦点管理和关闭语义不如 Dialog 清晰，也会改变用户已经熟悉的点击行为，因此不采用。

### 推荐方案：Hover Card 预览加 Dialog 详情

快速浏览与稳定阅读各自使用合适的容器，并能保持现有点击行为和权限边界。项目已有相关基础组件，不需要新增依赖，改动范围最小。

## 兼容性与风险

- 三列的管理员和普通用户可见性保持现状，不在前端放宽权限。
- 完整 JSON 可能很长，必须限制悬停层尺寸并让内容区域滚动，不能让浮层撑开页面。
- 点击时必须避免 Hover Card 遮挡 Dialog；Dialog 关闭后焦点应返回触发按钮。
- 列表紧凑化不能截断状态徽标、双行时间或复制型任务 ID；超长内容继续使用现有截断策略。
- 不新增用户可见文案时无需扩展 i18n；若实现中需要新增提示，必须同步全部前端语言文件。

## 测试与验证

- 更新任务审计列组件测试，验证三个非空数据入口均支持悬停/聚焦预览，并且点击仍打开对应详情 Dialog。
- 覆盖空数据不渲染交互入口、点击时关闭预览、完整 JSON 可见和复制按钮可访问名称。
- 增加日志表格布局回归测试，验证 `task`、`drawing` 使用紧凑桌面样式，`common` 和移动端不受影响。
- 运行受影响前端测试、`bun run typecheck`、涉及文件的 lint、格式检查和 `bun run build`。
- 启动本地前端，在桌面和移动视口检查三个悬停层的边界、滚动、点击切换、键盘焦点，以及任务日志和绘图日志的列密度与内容完整性。
