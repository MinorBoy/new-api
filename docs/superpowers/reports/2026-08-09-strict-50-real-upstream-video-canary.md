# 严格模式 50% 毛利率真实上游视频 Canary 验收报告

日期：2026-08-09

## 验收结论

本轮已成功启用成本核算严格模式，并将全局最低预计毛利率设置为 `50%`。成本覆盖从 `26` 个缺口清理为 `0`，页面和接口均显示 `323/323` 项已覆盖。

固定渠道提交 12 个真实视频渠道后，11 个渠道因预计毛利率低于 50% 在本地路由阶段被拦截，没有创建任务、成本请求或访问上游。OmegaAI `#49` 的预计毛利率为 `84.9034%`，通过严格门禁并真实请求上游；上游返回 HTTP 402“积分余额不足”，未创建视频任务。

因此，本轮可以确认严格毛利门禁正常生效，也确认了通过门禁的请求能够到达真实上游；但没有成功生成视频，整轮真实视频 Canary 的最终结论为“部分通过”。OmegaAI 失败后的成本请求仍停留在 `cost_unknown / incomplete_revenue`，这是尚未闭环的成本核算异常。

## Canary 请求

公共请求使用安全文本提示词：

`A white cloud moves slowly above a calm lake, steady camera, natural light.`

默认参数为 4 秒、16:9，并使用每个目标合同支持的 480p 或 720p。Secure 企业目标最短时长为 5 秒，因此使用 5 秒；Secure 特价要求至少一张图片，因此使用 Ark 文档示例图片。所有请求均省略 `generate_audio`。

执行脚本初次调用时出现 Windows PowerShell 向 `curl.exe` 传递 JSON 的编码问题，产生的 `invalid JSON request body` 仅在请求解析层返回 400，未进入路由、成本核算或上游；这些预检噪声不计入下表。随后改为 UTF-8 无 BOM 请求文件并完成正式验收。
