# 对象存储域名规则默认转存策略设计

## 背景

对象存储转存已支持全部转存和域名规则模式。现有域名规则模式在黑名单、白名单均未命中时固定不转存，无法满足“仅黑名单不转存，其他链接默认转存”的场景。

## 目标

在域名规则模式增加“默认转存 / 默认不转存”开关，使未命中任何域名规则的链接可以按管理员配置决定是否转存，同时保持旧配置行为不变。

## 判定规则

1. 对象存储总开关关闭时，不转存。
2. 全部转存模式下，所有合法 HTTP(S) 视频链接转存。
3. 域名规则模式下按以下顺序判定：
   - 命中黑名单：不转存；
   - 未命中黑名单但命中白名单：转存；
   - 未命中任何规则：按“默认转存”开关决定。
4. 黑名单优先级高于白名单。
5. 新字段默认值为 `false`，旧配置迁移后仍保持未命中规则不转存。

## 配置与接口

新增配置字段 `rules_default_transfer`，类型为布尔值，随对象存储配置持久化，并在管理接口的查询、更新、测试请求中传递。

## 管理页面

仅在“域名规则”模式显示“默认转存”开关：

- 开启：白名单之外、且未命中黑名单的链接按默认转存处理；
- 关闭：未命中规则的链接不转存。

页面继续显示白名单、黑名单开关及其输入框，并明确黑名单优先级和默认策略。

## 验证范围

- 后端规则判定覆盖黑名单优先、白名单命中、默认转存和默认不转存；
- 配置归一化与控制器接口覆盖新字段的默认值、读写和省略字段兼容；
- 前端覆盖开关的可访问名称、显示条件和请求提交值；
- 执行 Go 测试、前端组件测试、类型检查、lint 和构建验证。
